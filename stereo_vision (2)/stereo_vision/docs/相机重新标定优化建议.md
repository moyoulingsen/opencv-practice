# 相机重新标定优化建议

本文档用于指导后续同学在更换相机、重新采集数据、重新标定时，应该优先做哪些优化调整。

## 1. 先改什么，再拍什么

如果换了一台新的双目相机，不要直接沿用当前数据集重跑。建议先确认这 6 件事：

1. 确认输入形式
   - 是左右拼接一帧，还是左右两个独立设备
   - 如果是拼接，确认是 `left_right` 还是 `top_bottom`
   - 确认原始分辨率，例如 `2560x720`

2. 确认棋盘格参数
   - 内角点数量是否仍为 `8 x 6`
   - 单格尺寸是否仍为 `0.025 m`
   - 打印时是否 `100%` 实际尺寸，无缩放

3. 确认真实 baseline
   - 必须量两个镜头中心到中心的距离
   - 不要量外壳、边框、PCB 边缘

4. 确认标定板平整度
   - 必须贴在硬平面上
   - 不建议拿软纸直接拍

5. 确认镜头状态
   - 固定对焦时，不要在采集中再动焦距
   - 尽量固定曝光/增益/白平衡

6. 确认角点顺序
   - 先导出角点调试图，确认左右编号方向一致
   - 不一致时先修角点顺序，再谈标定质量

## 2. 采集阶段建议做的优化

### 2.1 数据量

- 推荐 `30-40` 组有效双目图像对
- 少于 `20` 组通常不稳

### 2.2 姿态覆盖

必须同时覆盖：

- 近、中、远距离
- 中心、四角、边缘位置
- 左右倾斜、上下倾斜
- 少量 roll 旋转

建议比例：

- `8-10` 张：正对、不同距离
- `10-12` 张：大倾角
- `8-10` 张：边缘/四角
- `4-8` 张：轻微旋转

### 2.3 图像质量

优先保证：

- 左右图都清晰
- 板完整可见
- 不贴边
- 不反光
- 不模糊

如果要在多张里做取舍，优先删：

- 角点顺序反了的图
- 严重模糊的图
- 板子太小的图
- 板子几乎贴边的图
- 与其他图姿态几乎一样的图

## 3. 标定参数推荐怎么设

对这类 UVC 广角双目，当前项目里验证下来更稳的组合是：

- `model: pinhole`
- `use_rational_model: false`
- `stereo_fix_intrinsics: false`
- `fixed_intrinsics: false`

也就是：

- 先使用简单 pinhole 模型
- 不要一上来用 `RATIONAL_MODEL`
- 不要一上来强行固定内参
- 先做联合优化，等有稳定结果后再考虑固定内参版本

原因：

- 简单模型不容易把误差“吃进”复杂畸变项
- 联合优化更容易在初期把双目外参收敛到正确尺度

## 4. 哪些情况要重点怀疑有问题

### 4.1 单目 RMS 好，双目 RMS 差

优先怀疑：

- 标定板不平
- 角点编号左右不一致
- 少量坏样本污染了整体结果
- baseline 实测值不准

### 4.2 极线矫正后比原图更差

优先怀疑：

- 当前 `R/T` 不对
- 当前标定还没收敛到正确外参
- 使用了不合适的模型或错误样本

### 4.3 alpha 调大后画面缩到角落

优先怀疑：

- OpenCV 原生 rectification 的主点位置偏了
- 应考虑 centered principal point 版本，而不是直接放弃该 `alpha`

## 5. 推荐的排查顺序

如果新相机第一次标定效果差，按这个顺序查：

1. 看角点图是否有左右编号不一致
2. 看标定板是否平
3. 看 baseline 是否量准
4. 看是否用了过复杂的单目模型
5. 看是否有几张明显坏样本
6. 再去比较不同 `alpha` 的极线矫正效果

## 6. 推荐复用的脚本

### 6.1 采集

- `stereo_vision/scripts/capture_pairs.py`

### 6.2 标定

- `stereo_vision/scripts/calibrate_stereo.py`

### 6.3 角点调试

- `stereo_vision/scripts/export_corner_debug.py`

### 6.4 极线调试

- `stereo_vision/scripts/export_rectification_debug.py`

### 6.5 alpha 扫描

- `stereo_vision/scripts/export_rectification_alpha_sweep.py`

### 6.6 实时矫正

- `stereo_vision/scripts/run_rectify_live.py`

## 7. 给后续同学的实际建议

如果他的相机也要重新标定，我建议直接按下面流程做：

1. 改 `configs/default.yaml` 里的分辨率、设备号、棋盘格参数
2. 用 `capture_pairs.py` 采 `30-40` 组原始图
3. 先导出角点图检查顺序和坏样本
4. 再跑 `calibrate_stereo.py`
5. 再看极线调试图，而不是只看 RMS
6. 最后再选运行时 `alpha`

一句话总结：

- 先保证数据和角点是对的
- 再谈模型和优化
- 先把标定跑对，再做部署优化
